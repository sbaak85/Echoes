# 遠星迴聲船艙預覽接續說明

日期：2026-10-14（Asia/Taipei）。這是可攜預覽套件內的交接文件，並非正式遊戲整合摘要。

## 開始方式

從套件根目錄執行 `node preview/server.mjs`，瀏覽 `http://127.0.0.1:3054/`；Windows 可雙擊 `start-preview.cmd`。
需要可用的 Node.js 和支援 WebGL 的瀏覽器。Three.js 0.180.0 及 OrbitControls 已放在 `preview/vendor/`。
所有執行資產都使用套件內的相對路徑，不依賴原電腦的遊戲資料夾。

本次 UI 工作適用 [專案 UI 技能](../../.codex/skills/browser-ui-focus-visuals/SKILL.md)。技能快照隨包附上；未宣告 UI 例外。

## 使用者已確認的方向

- 先做 Worktree 預覽，未授權整合正式遊戲或 Push。
- 船艙長條布局、中央通道、前端駕駛艙，依兩張 references 圖片建立幾何草稿。
- 駕駛艙向前收窄、微尖；前方保留觀測窗，兩側改為實體艙壁。
- 駕駛座位前各 2 組、共 4 組操控電腦；固定駕駛台不納入設備隱藏。
- 使用者明確否定「只把桌上螢幕換成小硬體」：必須呈現落地、壁掛、支架、不同高度深度，以及連接管線的安裝層次。
- 兩側機電區已有落地機櫃、壓力筒、壁掛配電箱、低位泵浦、高位風道和線槽。
- 其餘艙室也依用途加入掃描支臂、濾水與排氣、壓縮機、供應管線、壁櫃、衛生水路、貨物固定及吊運軌道。

## 功能與程式結構

- 9 道滑動門；各門開關與全部開關；可點擊場景門口。
- 19 組設備顯示開關，新增安裝構件跟隨所屬設備，不應留下殘留管線。
- 左右舷外壁分別顯示；隔間與比例網格另有開關。
- 正交總覽、駕駛艙近看、俯視、另一側、縮放、滑鼠旋轉與平移。
- 鍵盤方向鍵及程式實作的手把左搖桿/A 導覽；沒有在實體手把上完成驗收。
- `preview/scene.js`：Three.js 程式化建模、材質、門動畫、控制邏輯。
- `preview/index.html` / `style.css`：控制面板、響應式排版。
- `preview/server.mjs`：僅本機 HTTP 靜態服務，預設 3054；可攜版本新增 PORT 環境變數與占用錯誤提示。
- `equipment()` 管理隱藏群組；`retrofit()` 把新構件放回既有設備群組；`bridgeServiceBay()` 建立駕駛艙側邊安裝區。

## 驗證與界線

原預覽曾在瀏覽器實際載入並檢查兩側構圖；全部設備隱藏後沒有殘留安裝構件，恢復顯示正常；駕駛艙電腦計數為 4。
Node 語法檢查通過。家裡電腦的 GPU、瀏覽器、Node 路徑與啟動狀況仍需在當地確認。
這是比例化幾何草稿，尚未接入角色碰撞、尋路、任務、存檔或正式場景；沒有匯出成 GLB/FBX。
搬移檔案會保留模型來源與介面功能，但不會恢復上一台電腦的伺服器程序、瀏覽器分頁、鏡頭狀態或未保存的工具工作階段。
本包不含完整聊天紀錄或跨電腦記憶資料。新對話以此文件、原始碼和 references 作為接續依據。
