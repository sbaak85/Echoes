# ImageView — 輕量圖片瀏覽器

免安裝、單一執行檔（`ImageView.exe`，幾百 KB），使用 Windows 內建的 .NET Framework 4.8，Windows 10 / 11 不必另外安裝任何東西。

支援格式：`png` `jpg` `jpeg` `jpe` `jfif` `bmp` `dib` `gif`（含動畫）`tif` `tiff` `ico`
（webp / heic / avif 目前不支援）

---

## 安裝與檔案關聯

1. 把 `dist\ImageView.exe` 放到固定位置（例如 `D:\Tools\ImageView\`）。**之後不要再移動**，否則檔案關聯會失效。
2. 在圖片上按右鍵 →「開啟檔案」→「選擇其他應用程式」→ 最下方「在這台電腦上尋找其他應用程式」→ 選 `ImageView.exe`，並勾選「一律使用此應用程式開啟」。
3. 每種副檔名（png、jpg…）各做一次。

**可選：** 在 ImageView 視窗中按右鍵 →「檔案關聯」→「註冊到『開啟檔案』清單」。
這只寫入目前使用者的登錄檔（不需要系統管理員權限），讓 ImageView 以正確名稱和圖示出現在「開啟檔案」清單和 Windows「預設應用程式」設定中，可以一次把所有格式設給 ImageView。
不想用時選「移除註冊」即可清乾淨。也可以用命令列 `ImageView.exe /register`、`ImageView.exe /unregister`。

設定檔 `ImageView.ini`（只記錄視窗大小位置和背景色）會存在 exe 旁邊；如果該資料夾不能寫入，改存到 `%APPDATA%\ImageView\`。

## 規格與行為

### 視窗
| 狀態 | 行為 |
|---|---|
| 開啟圖片 | 在滑鼠所在的螢幕上**視窗最大化**（工作列仍可見） |
| 邊框 | 只有 1 個實體像素的矩形細框，無標題列；全螢幕時無邊框 |
| 雙擊（最大化或一般視窗） | 進入**全螢幕**（蓋住工作列） |
| 雙擊（全螢幕） | 退出全螢幕，回到之前的視窗狀態 |
| `Esc` | 全螢幕時：退出全螢幕，還原成進入全螢幕前的視窗大小；非全螢幕時：關閉程式 |
| 移動視窗 | 一般視窗狀態下，圖片沒有超出視窗時直接拖曳；或按住 `Alt` 拖曳；或拖曳功能列空白處（雙擊功能列空白處＝最大化／還原） |
| 調整大小 | 一般視窗狀態下，拖曳視窗邊緣（邊緣內側 6px 為隱形的調整區） |
| 同時只開一個 | 已經開著時再開另一張圖，會沿用同一個視窗 |

### 圖片顯示
- 預設以 **100%（1:1 實體像素）** 顯示，置中。大圖只會看到中間一部分（可以拖曳）。
- 手機照片依 EXIF 方向自動轉正。
- 每切換一張圖，底部顯示檔名（半透明陰影底色），**3 秒後自動淡出**。
- 顯示模式（1:1／符合高度／符合寬度）、縮放倍率、鍵盤位移、旋轉角度都會**延續到下一張**。
- 滑鼠拖曳的位置**換張後還原置中**。
- 圖片超出視窗時可以按住左鍵拖曳；位置不在中央時，**單擊一下**回到置中。
- 到最後一張再往下會回到第一張（畫面上方會提示）。
- 會預先載入前後張，切換不卡頓。

### 瀏覽順序
- 開啟時自動讀取**檔案總管目前視窗的排序**（名稱／日期／大小／類型…，含遞增遞減），並直接採用檔案總管畫面上的檔案順序，連自然排序都一致。
- 讀不到時（例如從命令列開啟、該資料夾沒有開著的檔案總管視窗），預設用「名稱、遞增、自然排序」。
- 右鍵 →「瀏覽排序依據」可改成：名稱、修改日期、建立日期、大小、類型，以及遞增／遞減；或重新「跟隨檔案總管」。

### 功能列
- 預設隱藏。右鍵 →「顯示功能列」後從頂端滑下，**覆蓋在圖片上、不推移圖片**，背景 50% 半透明。
- 10 秒內沒有在功能列上操作（移動滑鼠、點擊）就自動收回。
- 內容：上一張、下一張、縮小、放大、1:1、符合高、符合寬、左轉、右轉、重設｜圖片資訊（第幾張、檔名、尺寸、縮放比例）｜排序、複製、在檔案總管中顯示、刪除、全螢幕、最小化、最大化、關閉。

### 右鍵選單
顯示功能列／圖片符合視窗高度／圖片符合視窗寬度／還原圖片大小 (1:1)／瀏覽排序依據 ▸／強制全螢幕最大化／視窗最大化／向右旋轉／向左旋轉／重設所有調整／背景 ▸（深灰、黑、白、棋盤格）／開啟檔案／複製圖片／在檔案總管中顯示／刪除／檔案關聯 ▸／關閉

## 快速鍵

| 按鍵 | 功能 |
|---|---|
| `→` / 滾輪下 / `PageDown` / `空白鍵` | 下一張 |
| `←` / 滾輪上 / `PageUp` / `Backspace` | 上一張 |
| `Home` / `End` | 第一張 / 最後一張 |
| `↑` | 全螢幕 + 圖片符合螢幕高度 |
| `↓` | 退出全螢幕 + 圖片還原 100% |
| 左鍵雙擊 / `F11` | 切換全螢幕 |
| `Esc` | 退出全螢幕；非全螢幕時關閉程式 |
| 小鍵盤 `+` / `-`（主鍵盤 `=` `-` 也可以） | 放大 / 縮小 10%（乘以 1.1 倍），換張保持 |
| `Ctrl` + 滾輪 | 以滑鼠位置為中心縮放 |
| 小鍵盤 `8` `2` `4` `6` | 圖片往上／下／左／右移動視窗尺寸的 10%，換張保持 |
| 小鍵盤 `1` | 順時鐘旋轉 90°，換張保持 |
| 小鍵盤 `3` | 逆時鐘旋轉 90°，換張保持 |
| 小鍵盤 `5` | 重設所有調整（1:1、縮放、位移、旋轉） |
| 左鍵單擊 | 圖片不在中央時回到置中 |
| `Delete` | 移到資源回收筒（會先確認） |
| `Ctrl+C` | 複製圖片 |
| `Ctrl+O` | 開啟檔案 |
| `F5` | 重新讀取資料夾 |
| 右鍵 / 選單鍵 | 開啟右鍵選單 |

小鍵盤功能不受 NumLock 開關影響（程式會分辨小鍵盤和獨立方向鍵）。

## 從原始碼建置

需要 .NET SDK（任何新版即可）和 .NET Framework 4.8 Developer Pack（參考組件）。

```powershell
.\build.ps1
```

輸出：`dist\ImageView.exe`

專案結構：

| 檔案 | 內容 |
|---|---|
| `src/MainWindow.xaml(.cs)` | 視窗、顯示、熱鍵、滑鼠、功能列、右鍵選單 |
| `src/ExplorerOrder.cs` | 透過 Shell COM 讀取檔案總管視窗的排序與畫面順序 |
| `src/FileList.cs` | 資料夾列舉、自然排序 |
| `src/ImageLoader.cs` | 解碼（WIC）、EXIF 轉正、GIF 動畫合成 |
| `src/Registration.cs` | 可選的 HKCU 檔案關聯註冊／移除 |
| `src/Program.cs` | 進入點、單一實例（具名管道轉送） |
| `tools/make-icon.ps1` | 產生 `ImageView.ico` |

診斷用：`ImageView.exe --dump-order <圖片路徑> <輸出.txt>` 會把讀到的檔案總管排序與順序寫到文字檔。
