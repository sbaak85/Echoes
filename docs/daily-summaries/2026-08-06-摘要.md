# Echoes 每日摘要｜2026-08-06

## 完成事項

- QuestEditor 的任務、Stage 與 OBJ 已能分別設定「啟動延遲（秒）」。
- Stage 啟動延遲會從正式進入該階段後開始計算；OBJ 啟動延遲則從所屬 Stage 正式啟動後開始計算。
- 尚未啟動的 Stage／OBJ 不會顯示，也不接受拾取、互動等任務判定事件。
- Stage 與 OBJ 新增「完成延遲（秒）」。
- OBJ 條件達成後，可延後核取、完成 Tween 與完成事件。
- Stage 條件達成後，可延後 `NEXT`、任務完成 UI 與下一階段啟動。
- 正式版 `QuestEditor.exe`、README 與使用教學已同步更新。

## 沿用的技能與架構

- 延遲採現實時間秒數，使用絕對截止時間保存，不因重新讀檔而重新倒數。
- 任務邏輯完成與視覺完成演出分離：先保存完成，再延後 UI 與後續流程。
- 舊版任務資料未設定延遲時，維持 `0` 秒立即處理，避免破壞既有流程。

## 重要設計決定

- 完成條件成立當下，OBJ、Stage 及最終 Quest 的完成狀態與完成旗標立即寫入存檔。
- 即使在完成延遲倒數期間立即關閉遊戲，重新進入後仍保留完成紀錄，並接續尚未完成的延遲演出。
- OBJ 與 Stage 的完成延遲同步計時；兩者都結束後才執行階段切換或最終任務完成 UI。
- 啟動延遲與完成延遲的可設定範圍為 `0～3600` 秒。
- 正式任務資料中第三階段既有的「啟動延遲 1 秒」設定保留不變。

## 注意事項

- 完成延遲只延後核取動畫、完成演出與後續階段，不延後完成旗標本身。
- 測試任務時，延遲啟動中的 OBJ 收到的事件會被忽略；應等待目標正式出現後再觸發事件。
