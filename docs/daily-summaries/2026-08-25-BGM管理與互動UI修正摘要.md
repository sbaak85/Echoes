## 3. AudioEventManager 與 BGM 管理

- AudioEventManager 新增獨立「BGM 管理」頁籤，分為：
  - `BGM 素材庫`：Track ID、多首播放清單、基礎音量、Loop、是否記住播放進度。
  - `BGM 控制規則`：依 Quest、Stage、OBJ、小遊戲、章節、場景或特殊事件，設定調音量、暫時靜音或切換 Track。
- 規則支援優先權、FadeOut／FadeIn 秒數、持續時間，以及解除後續播、重播或回到預設 Track；狀態只在事件變化時重算，不做每幀掃描。
- 新增 `app/bgm-director.ts`，以雙 Deck 管理換曲、交叉淡化、播放位置記憶、Options BGM 音量及狀態同步。
- Quest 啟動事件是 Quest 型 BGM 規則的權威同步時機；另接上章節、場景、小遊戲與 `echoes:bgm-control` 特殊事件入口。
- BGM 原本兩首預設曲保留為 `default` Track，玩家尚未調整 Options 前的全域 BGM 音量為 35%。
- 原始素材與遊戲 MP3 路徑右側加入檔案總管按鈕，可直接定位第一個音檔；原始素材未填時，其定位與預覽按鈕停用。
- `AudioEventManager.exe` 與 MapEditor 內共用的 Audio 管理入口已重新建置。

## 4. 本機手把 Bridge 的瀏覽器錯誤抑制
