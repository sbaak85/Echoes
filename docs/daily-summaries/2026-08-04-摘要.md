## 四、任務提示 UI 與生存 UI

- 任務提示板與生存狀態板共用平滑高度 Tween。
- 收折／展開時間統一為 `0.3 秒`。
- 動畫只改變實際需要變化的高度；寬度與標題列尺寸固定，不會每次重新縮放整塊 UI。
- 展開或收折途中再次切換時，會從當前高度繼續，不會跳回動畫起點。
- 生存 UI：
  - Day／Time 標題列維持相同大小。
  - 大型與縮小版計量以遮罩及 Fade 交換，收折時不會瞬間消失。
  - PC 預設展開，除非玩家自行收折。
- 任務 UI：
  - 標題列折疊與展開維持一致高度。
  - 移除上下兩條多餘裝飾細線。
  - 三角箭頭固定在標題列。
- 目前主要字級：
  - 任務標題：`20px`
  - 任務進度：`17px`
  - 任務目標內文：約 `18px`
  - 生存標題與計量文字依同一比例調整。
- 快捷操作：
  - PC：`Q` 收折／展開任務 UI，`R` 收折／展開生存 UI。
  - 手把：`RB` 收折／展開任務 UI，`LB` 收折／展開生存 UI。

## 五、NEXT／COMPLETE／FAILED 任務演出

- NEXT、COMPLETE、FAILED 出現時，原任務標題在主演出區間會完全隱藏，不再從事件文字後方透出。
- 三種演出底光均提高亮度、濃度與內發光：
  - NEXT：金色。
  - COMPLETE：綠色。
  - FAILED：紅色。
- 底光刷出方式已改為：
  1. 從標題列最左側開始。
  2. 平滑地由左向右刷滿。
  3. 短暫停留。
  4. 整體柔和 Fade Out。
- 移除早期 `8%／10%` 的中途速度關鍵幀，避免刷光在約 10% 位置產生頓挫。
- 任務完成／失敗的外框震波：
  - 從現有任務框 `100%` 尺寸開始。
  - 再向外擴張至約 `110% × 120%`。
  - 擴張期間同步 Fade Out。
  - 不再從比任務框更小的 `92%` 內框開始。
