# Echoes 開發摘要｜2026-08-01

## 完成事項

- 啟用遊戲時間與生存狀態管理，遊戲 24 小時等於現實 1 小時。
- 實作體力、飢餓、口渴、精神的自然消耗、臨界警告、移動速度減益與 Game Over 條件。
- 實作人物頭頂狀態文字，包含疲憊、飢餓、口渴、精神不濟、喪氣與絕望；同時最多顯示三項。
- 生存狀態、遊戲時間及每日互動次數可保存在本機。
- Options、背包及對話開啟時，暫停遊戲時間與生存消耗。
- MapEditor 新增對話、操作、採集、移動、互動五種互動類型。
- MapEditor 新增「消耗設定」，可調整四項生存值，並設定每日互動次數為 1～10 或無限。
- 有限互動次數於每日 06:00 重置；用完後，遊戲中的互動提示點改顯示灰色 X。
- 已將測試場景中的互動區依用途套用對話、操作、移動與採集設定。

## 學到或沿用的技能

- 將時間曲線、生存數值、狀態判定、每日重置與儲存集中在獨立管理模組，避免分散於畫面控制程式。
- 使用平滑餐期曲線處理早餐、午餐、晚餐的額外飢餓消耗。
- MapEditor 與遊戲共用同一份場景 JSON；編輯器新增欄位後，同步補上遊戲端解析與執行規則。
- 修改 MapEditor 原始碼後，需重新發佈並替換正式的 `MapEditor/MapEditor.exe`。

## 重要設計決定

- 早餐、午餐、晚餐分別以 08:00、12:00、18:00 為中心，各形成前後一小時的平滑曲線。
- 飢餓基礎消耗為每遊戲小時 −0.5，三餐各額外約 −10，每日平均約 −42。
- 體力每日自然消耗 25，低於 10 後不再自然下降；移動、互動及事件仍可使其繼續下降。
- 體力、飢餓、口渴的速度減益採乘算，三項同時臨界時速度約剩 68.85%。
- 四項生存值同時臨界時，「絕望」取代「喪氣」。
- 預設互動消耗：操作 −5/−3/−3/0；採集 −4/−2/−2/−1 且每日三次；一般互動 −1/−1/−1/0。

## 注意事項與已知問題

- 生存消耗速度目前是第一版基準，仍需長時間實際遊玩確認節奏是否過快。
- Game Over 與重新開始目前以測試流程為主，未來需再與正式存檔、死亡或救援流程整合。
- 食物、飲水、睡眠與休息等恢復來源尚未接入正式道具及互動內容。
- 本輪修改尚未要求 Commit 或 Push。
