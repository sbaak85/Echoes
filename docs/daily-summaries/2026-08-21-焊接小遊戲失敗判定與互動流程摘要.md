# 2026-08-21 焊接小遊戲失敗判定與互動流程摘要

## 摘要用途

本文件記錄 2026-08-21 完成的焊接小遊戲正解預覽、錯路失敗判定、失敗演出、正式任務互動整合、手把介面、MapEditor 與任務零件繳交流程。

前一份 [`2026-08-20-焊接小遊戲修改摘要.md`](./2026-08-20-焊接小遊戲修改摘要.md) 所記載的「不抽選正解、不播放開場預覽、不判斷錯路」已被今天的實作取代。候選焊線、分支描繪、折返與棄線淡出的基礎規則仍然保留。

## 專案 UI Skill

本次涉及瀏覽器小遊戲、確認視窗、虛擬游標、按鈕與手把導覽，後續建立、修改、檢查或測試時必須套用專案技能：[`.codex/skills/browser-ui-focus-visuals/SKILL.md`](../../.codex/skills/browser-ui-focus-visuals/SKILL.md)。本次沒有刻意例外。

重點仍是：隱藏瀏覽器原生 focus 視覺、保留遊戲自訂選取效果、依最後輸入方式分配控制權，以及讓確認視窗預設支援左搖桿／方向鍵導覽與 A 鍵啟動。

## 焊接正解與開場流程

- 每次建立全新焊接小遊戲 session 時，會隨機抽選一條由左至右、在交錯分岔處隨機選路的正確路線。
- 正式取得玩家控制權之前會先開啟說明確認畫面，玩家選擇「開始預覽路線」後才進入倒數。
- 倒數為 3、2、1，接著由焊槍自動走過一次本局正確路線。
- 預覽結束後才開放玩家實際焊接。
- 說明確認畫面與成功確認畫面保留一般滑鼠及手把虛擬游標；進入倒數、預覽與實際焊接階段後才隱藏一般虛擬游標。
- 避免開啟互動時同一個 A 鍵持續按住而直接略過說明，確認輸入必須先放開再重新按下。

## 錯路判定規則

### 節點判斷

- 正解方向的比對以圖節點為主，不在每幀重新做完整路線判斷。
- 起點、終點與有選路意義的分歧節點會啟動一次方向比對。
- 單一路徑上的普通轉角不需要比對，避免增加無意義判斷。
- 玩家即使選錯分支，紅色高熱焊線仍會正常貼著實際走過的路線描繪，不會停在路口洩漏答案。

### 100px 容許距離

- 從節點確認選入錯誤分支後，開始累計錯誤移動距離。
- 距離採畫面實際渲染比例換算，錯誤距離超過 `100px` 才觸發失敗。
- 玩家沿原錯路折返時會扣回錯誤距離，不會把折返行為繼續累加成失敗。
- 回到節點並改走正確方向後，錯路狀態會解除。

### 終點是強制檢查點

- 抵達任何終點時都必須立即比對本局正解。
- 抵達正確終點即完成小遊戲。
- 抵達錯誤終點時，即使該分支尚未走滿 100px，也立即判定失敗。

## 焊線基礎表現保留項目

- 所有可見 graph edge 都能磁吸紅色焊線，包含錯誤分支。
- PC 滑鼠本身不吸附在線上；只有紅色焊線投影在線上。
- 手把模式為降低右搖桿操作難度，焊槍／焊點才會在按住 RT 焊接時輔助磁吸。
- 放開 RT 後可以自由移動，再回到中斷處按住 RT 繼續焊接。
- 玩家折返並確定改走其他分支後，先前放棄的短分支會以 `720ms` FadeOut。
- 多次放開再起焊時，候選焊線仍使用 `trailId`、18 單位續接距離、預備棄線與重新奪回領先後才淘汰舊線的規則。
- 玩家第一個有效位移即使用正式高熱焊線效果，不再出現首段延遲、假種子線或深紅外緣。

## 失敗演出

失敗後會立即鎖定焊接控制，不會瞬間關閉視窗：

1. 顯示「焊接錯誤了」。訊息使用 0.2 秒 FadeIn、停留 1 秒、0.2 秒 FadeOut，總長 1.4 秒。
2. 進入 1.8 秒路線檢視：玩家走過且屬於正解的段落較慢發亮閃爍 3 次；錯誤段落在同一階段立即轉成黑色焦痕，不必等待正確段落閃完。
3. 小遊戲面板以 `420ms` Tween 縮小並淡出，之後才真正關閉。
4. 現階段只顯示「金屬碎片 -1」假訊息，尚未真正扣除 Item。

失敗不得送出 `interactionSucceeded`、`puzzleCompleted` 或消耗唯一一次互動額度。

## 焊接音效與火星

- 新增兩層焊接循環音效：`焊接1.mp3` 與 `焊接2.mp3`。
- 遊戲載入檔案位於 `public/audio/welding-sparks-1.mp3`、`public/audio/welding-sparks-2.mp3`。

- 焊接期間使用透明火星素材與密集火星粒子；預覽與玩家實際焊接皆會啟動火星及混音。

## 正式任務整合

### `scene3-interaction-024`

- 啟用階段：`QUEST_CH03_MAIN_006_STAGE_02`。
- 任務目標：`QUEST_CH03_MAIN_006_OBJ_04`，類型為 `puzzleCompleted`。
- 互動條件包含生存數值與焊槍工具 `R0009`。
- 條件成立後，必須先播放互動成功台詞「準備好可以開始組裝了。」；台詞結束後才開啟小遊戲說明確認畫面。
- 小遊戲成功且玩家確認完成後，才結算原互動並送出 `puzzleCompleted`。
- 小遊戲失敗只關閉小遊戲與顯示假扣除訊息，不消耗 `scene3-interaction-024` 的唯一一次互動。
- `QUEST_CH03_MAIN_006_OBJ_04` 的完成 UI 效果延遲為 2.5 秒，不影響真實完成狀態。

### `scene3-interaction-023` 任務零件繳交

此互動對應 `QUEST_CH03_MAIN_006_STAGE_01` 的三個 OBJ：

- `R0013`：通訊陣列面板。
- `R0014`：量子傳輸器。
- `R0015`：校正元件。

目前對話與投入規則：

- 身上沒有任何可繳交零件：播放互動失敗對話，不開啟投入確認視窗。
- 身上有 1～2 個可繳交零件：先播放一次互動成功對話，再開啟投入確認視窗；每投入一項就完成對應 OBJ，但不播放最終完成對話。
- 身上有全部 3 個零件：成功對話只播放一次，之後依序投入；三個 OBJ 全部完成後才播放互動完成對話。
- 既有投入確認視窗的滑鼠、方向鍵／左搖桿、A 確認與 B 取消操作維持不變。

## MapEditor

- 按下圖示會將完整互動 ID 寫入剪貼簿，狀態列顯示複製結果。
- 沒有選取互動多邊形時不顯示此按鈕。
