# 2026-08-22～2026-08-23 週末系統改版重點摘要

## 摘要定位

- 本文件整理 2026-08-22～2026-08-23 週末完成的主要系統改版，作為後續開發、跨電腦 Pull 與問題追查的交接基準。
- 週末程式改動已整合於 Git 提交 `f7c2402f9d1cd98ac48da1ca6e52e5399b75a607`（`上傳改版更新`）。
- 專案唯一正式根目錄為 `I:\Codex\專案型\Echoes`；舊的 D 槽路徑只視為歷史位置。
- 專案摘要統一存放於 `docs/daily-summaries`，後續更新進度或注意事項時應先讀取此資料夾內修改日期最新的 Markdown。

## UI 共通規則

- 本次涉及的背包、快捷列、道具確認視窗、任務投入視窗、對話框、焊接／調頻／電力分配小遊戲與虛擬游標，皆適用 [browser-ui-focus-visuals 專案 UI Skill](../../.codex/skills/browser-ui-focus-visuals/SKILL.md)。
- 阻擋型 UI 開啟時，虛擬游標與確認輸入不得穿透至後方世界互動物件。
- 隱藏原生瀏覽器 Focus 外框，保留專案自己的選定／聚焦視覺；選單與可點擊按鈕預設支援左搖桿導覽與 A 鍵啟用。
- 輸入模式依最後實際使用的裝置切換；僅連線但未操作的手把不得搶走滑鼠操作權。
- 本次沒有刻意排除上述 UI 規則的例外。

## 1. 專案搬移與本機工具

- 新增 `echoes-project-relocation` Skill，記錄專案路徑更動後啟動器、依賴、建置、Git Local、MapEditor 與執行檔的修復及驗證方式。
- `啟動遊戲.bat`／`scripts/start-game.ps1` 改為由目前專案根目錄推導路徑，避免繼續引用舊磁碟位置。
- MapEditor 維持與遊戲共用 `public/maps`；地圖編輯器原始碼與 `MapEditor.exe` 已同步更新。
- 新增 `echoes-project-summaries` Skill，將所有日常／臨時／注意事項／特殊情況／交接摘要集中至 `docs/daily-summaries`。

## 2. 道具 `useAction` 與道具變化視覺化

- 道具資料新增共用 `useAction`：可自訂動詞、消耗數量、產出道具、數量及投遞位置（地面或背包）。
- 從背包或快捷列使用 `useAction` 道具時，統一先顯示確認視窗，例如「確認拆解／打開／使用 A，以取得 B 嗎？」；確認後才真正扣除與產出。
- 已設定：
  - `多功能工具箱`：打開後消耗 1 個，在角色附近生成 `銲槍工具 ×1`。
  - `金屬零件`：拆解後消耗 1 個，在角色附近分別生成 3 個獨立的 `金屬碎片`，不是一個 `×3` 堆疊。
- 成功生成地面產物後會關閉背包；單純增加生存數值的食品／飲水使用後仍保持背包開啟。
- 道具資訊欄若為 `useAction`，顯示「可拆解成／可打開取得……」；只有實際具備生存影響數值時才顯示「生存影響」。
- `useAction` 確認視窗以「來源道具 Icon → 目標道具 Icon」呈現變化；數量與名稱版面已放大並依多欄空間自動縮放，避免 Label 重疊。
- 任務投入也共用相同的 Icon 變化元件：持有者正常點亮、未持有者半透明、已投入者顯示綠底勾選。
- 最後一項投入成功時，會先顯示一次綠色完成勾選，再延遲關閉需求視窗。
- 背包手把操作已修正為第一次點擊只選定與顯示資訊，第二次點擊同一格才使用；對話與背包同時開啟時，B 鍵會先關閉背包。
- `R0013`、`R0014`、`R0015` 已歸類為任務道具。

## 3. 通訊陣列投入流程

- `scene3-interaction-023` 依序接收 `R0013 通訊陣列面板`、`R0014 量子傳輸器`、`R0015 校正元件`。
- 視窗左側顯示三項需求道具，右側以箭頭指向通訊陣列目標圖；「目前持有」會列出全部需求道具及各自背包數量，不再只顯示第一項。
- 通訊陣列採用專用 240×240 Icon：`public/ui/interactions/communication-array-tower-icon.png`。此圖代表場景目標，不視為背包道具。

## 4. ItemPoint 與 MapEditor ID

- ItemPoint 改為 Scene 唯一 ID，例如 `scene2-item-point-001`，避免不同場景的同名 ItemPoint 共用拾取／重生進度。
- 舊版 ItemPoint 進度具備遷移處理；現有場景與任務階段引用已改用 Scene 唯一 ID。
- MapEditor 圖層清單及選取欄會顯示完整 ItemPoint ID。
- 劇情觸發區、出入口多邊形及 ItemPoint 只要具有 ID，欄位旁皆提供複製文字按鈕。

## 5. 焊接小遊戲與耗材流程

- `scene3-interaction-024` 正式要求背包同時具備 `T0007 銲槍工具` 與 `R0009 金屬碎片` 才能進入焊接流程。
- 焊接失敗會扣除 `金屬碎片 ×1`、顯示扣除訊息、播放 `chapter03-special-1` 對話，並由 AudioEventManager 播放 `焊接失敗.mp3`。
- 背包只剩銲槍、沒有金屬碎片時，下一次互動會在進入小遊戲前被需求條件擋下。
- 路線規則改為必須由最左側入口開始並抵達正確終點；起點提供約 50 px 容許範圍。未經有效起點移動超過 100 px，或直接抵達終點，皆進入失敗流程。
- 四個入口改用固定位置的紅色 Blur Glow 提示，搭配較小且靠左的 `START` 字樣與向下箭頭；提示本身只呼吸亮度，不位移晃動。
- 正式操作前先顯示加高的路線說明視窗，循環播放虛線路徑、銲槍移動、火花、紅色焊線與方向箭頭。
- 預覽過程中滑鼠進出示範區不再造成銲槍圖像消失。
- 成功底板改為與失敗底板一致的 Fade In，不再由中央向左右展開；文字為「焊接成功」。
- 成功狀態移除右上角「離開」及其他取消路徑，只保留「確認完成」，避免成功後誤觸離開而遺失進度。
- 焊接成功綠底出現時，由 AudioEventManager 播放一次 `調頻成功.mp3`。

## 6. `QUEST_CH03_MAIN_006` 正式任務流程

- Stage 01：透過 `scene3-interaction-023` 分三次投入通訊陣列所需元件。
- Stage 02：完成 `scene3-interaction-024` 焊接及其成功對話後，核取 `QUEST_CH03_MAIN_006_OBJ_04`。
- OBJ 04 完成後必須先完整播放 `chapter03-section-8`，才啟動 `QUEST_CH03_MAIN_006_STAGE_03` 並開放 `scene3-interaction-025`。
- Stage 03：與 `scene3-interaction-025` 互動時先播放「可互動時」腳本，腳本播完才開啟調頻小遊戲；調頻成功後完成 `QUEST_CH03_MAIN_006_OBJ_05` 及整個任務。
- `QUEST_CH03_MAIN_006_OBJ_06` 是 Stage 02 的隱藏提示目標：對 `scene3-interaction-024` 需求互動失敗累積 2 次後，以事件 `scene3-interaction-024-failed-twice` 啟用。
- OBJ 06 判定持有 `T0007`，且 `blocksStageCompletion = false`；從未啟用或尚未完成都不阻擋正式焊接目標推進。
- 任務系統的「目前持有量」在讀檔、背包變更及事件目標啟用時都會同步查核；因此事件啟用當下若已持有 `T0007`，OBJ 06 會立即完成。
- 兩次失敗計數會保存於任務互動狀態，跨讀檔不會遺失或重複觸發。

## 7. 任務 Debug 快轉系統

- 新增 Scenario 式任務 Debug：以獨立 Debug 存檔及 `debugAutoResolved` 標記重建目標任務前的永久影響，而不是只呼叫任務完成。
- 快轉會補齊前置旗標、完成歷史、場景／互動狀態、背包、腳本、小遊戲、生存值及必要傳送，再正常啟動指定 Quest／Stage。
- 支援 `Quest Next`、`Quest Goto <任務>`、`Quest Goto <任務> Stage <階段>`、`Quest Stage Next`。
- 快速鍵 `]`：單擊或未滿 0.5 秒放開時只跳過一個 Stage；長按滿 0.5 秒只跳過一個 Quest，放開時不會再額外跳 Stage。
- `QUEST_CH03_MAIN_006` 另外補入 `chapter03-section-8` 等明確歷史資料，避免此任務缺少直接前置 Quest ID 時產生不完整世界狀態。

## 8. 電力分配、調頻與 AudioEventManager

- `interaction-012` 已取消暫時的兩個小遊戲選單，改為直接開啟電力分配小遊戲。
- 電力分配右下主操作改為黃色「啟動供電」按鈕；手把模式顯示 `(RT)` 並可用 RT 直接觸發。
- 成功啟動發電機後的第一段、第二段及運作聲會自然播放結束；各 Audio Event 支援按音檔總長百分比設定 `FadeIn`／`FadeOut`。
- 發電機三段音效設定為 `FadeIn 0%`、`FadeOut 15%`，不需要額外停止事件。
- AudioEventManager 與編輯器新增／更新下列成功事件：
  - `interaction-006` 生成藍色晶體碎片：`採礦聲1.mp3`。
  - 使用 `緊急口糧`：`飲食1.mp3`。
  - 使用 `淨水瓶`：`飲水2.mp3`。
  - 使用 `外星果實`：`吃水果.mp3`。
  - `interaction-020` 成功互動：`拆開面板2.mp3`。
  - 焊接失敗：`焊接失敗.mp3`；焊接成功：`調頻成功.mp3`。
- 道具音效只在背包／快捷列實際結算成功後播放，取消或使用失敗不播放。
