# Echoes 章節腳本編輯器

雙擊 `ChapterScriptEditor.exe` 即可編輯 `app/story-content.ts`。

## 第一版功能

- 上方以章節分頁管理內容，最右側 `＋` 可新增章節。
- 每章可設定頁籤名稱、章節標題、章節 ID 與章節編號。
- 可建立多筆黑畫面白色字幕事件，設定觸發條件、觸發次數、字幕內容與各段演出秒數。
- 可建立多個獨立對話段落，並沿用發話者、逐字速度、抽選群組與權重等對話編輯功能。
- 每句對話都有可見、唯讀且穩定的 `Line ID`；插入或上下移動台詞不會改號，可供 BGM 等事件精確觸發。
- 每個章節頁籤都有獨立的「劇情多邊形台詞」區；其中的對話 ID 可直接填入 MapEditor 的劇情觸發多邊形。
- 黑幕字幕、章節流程對話與劇情多邊形台詞預設各顯示約四列，兩條水平分隔線都可拖曳調整高度。
- 儲存前會檢查 ID、空白內容與重複資料。
- 儲存時會更新 `app/story-content.ts`，並在本機保留 `.bak` 與日期備份。
