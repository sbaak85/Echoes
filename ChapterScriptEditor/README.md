# Echoes 章節腳本編輯器

雙擊 `ChapterScriptEditor.exe` 即可編輯 `app/story-content.ts`。

## 第一版功能

- 上方以章節分頁管理內容，最右側 `＋` 可新增章節。
- 每章可設定頁籤名稱、章節標題、章節 ID 與章節編號。
- 可建立多筆黑畫面白色字幕事件，設定觸發條件、觸發次數、字幕內容與各段演出秒數。
- 可建立多個獨立對話段落，並沿用發話者、逐字速度、抽選群組與權重等對話編輯功能。
- 每句對話都有可見、唯讀且穩定的 `Line ID`；插入或上下移動台詞不會改號，可供 BGM 等事件精確觸發。
- 每個章節頁籤都有獨立的「劇情多邊形台詞」區；其中的對話 ID 可直接填入 MapEditor 的劇情觸發多邊形。
- 黑幕字幕、章節流程對話與劇情多邊形台詞預設各顯示約四列，兩條水平分隔線都可拖曳調整高度。
- 儲存前會檢查 ID、空白內容與重複資料。
- 儲存時會更新 `app/story-content.ts`，並在本機保留 `.bak` 與日期備份。

## 2026-10-09 操作改善

- 對話段落表格的「對話 ID」旁有「複製」按鈕；選取列後按 `Ctrl+C` 也會只複製 ID。
- 段落操作按鈕改為表格上方可換行的工具列，小螢幕也不會被裁切；視窗初始尺寸限制在螢幕工作區內。
- 新增／修改段落時，名稱與對話 ID 在同一個視窗設定：ID 依名稱自動建議（任何「第N章」都轉成 `chapterNN`），即時檢查空白、重複與非英數字元。
- `Ctrl+S` 儲存；有未儲存修改時標題列顯示「＊」。
- 日期備份只保留最近 30 份。
- 對話編輯視窗（與 MapEditor 共用）：
  - 列高依文案自動調整，視窗高度依句數延展（最少為螢幕的 50%、最高 90%）。
  - 發話者下拉選單有「（旁白／無發話者）」選項，空白發話者顯示灰色「— 旁白 —」；選單會列出其他段落實際用過的發話者，大小寫不同的輸入會自動對齊既有名稱。
  - 新增一句時沿用目前那句的發話者。
  - 「字數」欄超過 96 字（遊戲單頁上限）以橘色標示約略頁數。
  - 「複製 Line ID」按鈕與右鍵選單（複製 Line ID／文案、設為旁白）；`Ctrl+S` 儲存腳本。
